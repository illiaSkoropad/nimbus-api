This page provides a detailed breakdown of all available endpoints. The base URL for all API requests is:

`https://api.nimbus.com/v1`

---

## Get Current Weather

Returns the current weather conditions for a specified city.

`GET /weather/current`

### Parameters

| Parameter | Type   | Required | Description                             |
| :-------- | :----- | :------- | :-------------------------------------- |
| `city`    | string | Yes      | The name of the city (e.g., `Lviv`).    |
| `key`     | string | Yes      | Your unique API Key for authentication. |

### Example Request

<Tabs>
  <TabItem label="cURL">
    ```bash
    curl -X GET "https://api.nimbus.com/v1/weather/current?city=Lviv&key=YOUR_API_KEY"
    ```
  </TabItem>
  <TabItem label="JavaScript">
    ```javascript
    fetch('https://api.nimbus.com/v1/weather/current?city=Lviv&key=YOUR_API_KEY')
      .then(response => response.json())
      .then(data => console.log(data))
      .catch(error => console.error('Error:', error));
    ```
  </TabItem>
</Tabs>

### Example Response (`200 OK`)

```json
{
  "request_time": "2025-09-04T10:00:00Z",
  "city": "Lviv",
  "temperature_celsius": 19,
  "condition": "Cloudy with outbreaks of rain",
  "wind_kph": 12,
  "humidity_percent": 65
}
```

## Get 5-Day Forecast

Returns a 5-day weather forecast for a specified city.

`GET /weather/forecast`

### Parameters

| Parameter | Type   | Required | Description                             |
| :-------- | :----- | :------- | :-------------------------------------- |
| `city`    | string | Yes      | The name of the city (e.g., `Odesa`).   |
| `key`     | string | Yes      | Your unique API Key for authentication. |

### Example Request

<Tabs>
  <TabItem label="cURL">
    ```bash
    curl -X GET "https://api.nimbus.com/v1/weather/forecast?city=Odesa&key=YOUR_API_KEY"
    ```

  </TabItem>
